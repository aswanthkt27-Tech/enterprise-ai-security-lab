# Enterprise AI Security Lab

This project is an enterprise-style AI chatbot backend built for learning, development, and security testing.

## Current Features

- Express.js backend
- SQLite employee database
- OpenAI API integration
- Employee-based access control
- HR assistant chatbot endpoint
- Basic RBAC logic for employee, HR, and manager roles

## Planned Enterprise Enhancements

- Azure Entra ID authentication
- PostgreSQL cloud database
- Audit logging
- Role-based access control middleware
- Agent-style chatbot orchestration


## Development Workflow

All development must follow a professional Git workflow:

1. Do not directly modify `main`
2. Create a feature branch for every change
3. Test locally
4. Commit with a clear message
5. Merge only after review
